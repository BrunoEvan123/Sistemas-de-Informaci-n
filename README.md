## ✦ Sobre el proyecto

**A primera vista** es un proyecto académico desarrollado a partir de un emprendimiento real de **flores eternas artesanales elaboradas con limpiapipas**. Fernanda, la emprendedora, ofrece arreglos de catálogo y pedidos personalizados, combinando creatividad, dedicación y atención directa a sus clientes.

Nuestro propósito es comprender cómo funciona su proceso de venta y proponer una experiencia web que facilite la consulta de productos y la organización de solicitudes, respetando el valor del trabajo artesanal.

> Nuestra **idea central** es usar la tecnología para **acompañar** cada detalle hecho a mano, no para reemplazarlo.

## ✦ El reto

Fernanda promociona sus productos en Instagram y atiende solicitudes por WhatsApp. Para presentar las opciones disponibles, comparte fotografías y precios manualmente; después conversa con cada cliente sobre su elección, el adelanto y la coordinación de entrega.

Este proceso implica tareas repetitivas de atención que se vuelven especialmente relevantes cuando aumentan las consultas en fechas especiales. **La oportunidad de mejora** consiste en facilitar el acceso a la información de los arreglos y ofrecer una forma más ordenada de gestionar las solicitudes.

## ✦ Nuestra propuesta

Desarrollar una aplicación web orientada a dos experiencias complementarias:

- **Para los clientes:** explorar un catálogo de flores eternas, conocer sus características y solicitar un ramo de catálogo o personalizado.
- **Para Fernanda:** consultar las solicitudes recibidas, organizarlas por fecha y dar seguimiento a su preparación y entrega.

La propuesta nace del análisis **AS-IS** (proceso actual) y **TO-BE** (proceso propuesto), y se organiza mediante **Scrum**, **Product Backlog**, **Sprint Backlog** y la definición de un **producto mínimo viable** (MVP).

### ✧ Recorrido propuesto

```text
Explorar el catálogo
         ↓
Elegir un arreglo o personalización
         ↓
Enviar la solicitud
         ↓
Revisión y confirmación por Fernanda
         ↓
Verificación del adelanto acordado
         ↓
Elaboración o preparación del ramo
         ↓
Coordinación de la entrega
```

Este recorrido describe **la experiencia que buscamos construir**, no una afirmación de que todas sus etapas ya estén disponibles en el sitio. En el proceso comercial informado por Fernanda se contempla un adelanto del **50 %** y el saldo contra entrega.

## ✦ Exploración local

Para consultar el código del proyecto:

1. Clona el repositorio o abre sus archivos directamente desde GitHub.
2. Ingresa a `Trabajo_grupo/index/` y abre `index.html` en Visual Studio Code.
3. Si deseas visualizarlo mediante un servidor local, configura las rutas de CSS y JavaScript según la raíz desde la que se sirva la carpeta del proyecto.

```bash
# Clonar el repositorio del equipo
git clone https://github.com/BrunoEvan123/Sistemas-de-Informaci-n.git
```

> **¡Nota técnica de futura y próxima corrección!:** el HTML inspeccionado referencia `/styles/style.css` y `/script/script.js`. Como esas rutas parten de la raíz del servidor, deben verificarse según la configuración utilizada. Explorar el HTML no equivale a comprobar todo el flujo de compra.

## ✦ Metodología y trabajo colaborativo

Somos un equipo de **cinco estudiantes de Ingeniería Informática**. Aplicamos Scrum como marco de organización académica para trabajar en incrementos, revisar resultados y ajustar nuestra propuesta a partir del aprendizaje obtenido.

Para colaborar con el código, recomendamos crear una rama para cada cambio, redactar commits descriptivos, comprobar el resultado y abrir un *pull request* para su revisión antes de integrarlo a `main`.

Por un tema de **seguridad** no incluir contraseñas, tokens, credenciales de base de datos ni información personal de clientes en este repositorio público.

Quedan pendientes la implementación de estilos e interacciones, la validación de contenido comercial, las pruebas funcionales y la integración de los módulos que el equipo acuerde desarrollar.
